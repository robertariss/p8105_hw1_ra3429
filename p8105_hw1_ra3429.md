# Section 2: Description of the Penguins Data Set

The penguins data set consists of the following:

- There are 344 rows within the penguins data set.

- There are 8 columns within the penguins data set.

- The 344 rows represent data on each individual penguin

- The 8 columns represent characteristics of each penguin including
  species, island, bill_length_mm, bill_depth_mm, flipper_length_mm,
  body_mass_g, sex, year

- For example, the mean flipper length in penguins without missing data
  was 200.92
