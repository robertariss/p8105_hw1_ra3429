# Section 3: Variable Types and Coercion

We will create a dataframe with multiple types of variables as below:

``` r
problem_3_df = 
  tibble(
    problem_3_num = rnorm(10),
    problem_3_fac = problem_3_num > 0,
    problem_3_char = c("my", "name", "is", "rob", "this", "is", "the", "homework", "one", "submission" ),
    problem_3_factor = factor(c("NYHAI", "NYHAII", "NYHAIII", "NYHAI", "NYHAII", "NYHAIII", "NYHAI", "NYHAII", "NYHAIII", "NYHAI"))
  )
```

We will attempt to take the mean of each of these types of variables:

``` r
mean(pull(problem_3_df, problem_3_num))
```

    ## [1] -0.2823667

``` r
mean(pull(problem_3_df, problem_3_fac))
```

    ## [1] 0.3

``` r
mean(pull(problem_3_df, problem_3_char))
```

    ## Warning in mean.default(pull(problem_3_df, problem_3_char)): argument is not
    ## numeric or logical: returning NA

    ## [1] NA

``` r
mean(pull(problem_3_df, problem_3_factor))
```

    ## Warning in mean.default(pull(problem_3_df, problem_3_factor)): argument is not
    ## numeric or logical: returning NA

    ## [1] NA

We are unable to calculate a mean for character or factor type
variables.

Instead, we will try to convert variables to numeric:

``` r
as.numeric(pull(problem_3_df, problem_3_fac))
as.numeric(pull(problem_3_df, problem_3_char))
```

    ## Warning: NAs introduced by coercion

``` r
as.numeric(pull(problem_3_df, problem_3_factor))
```

We are only able to convert the logical and factor variables and not the
string type character variable to numeric. We cannot convert the
character string type variable to a meaningful number, so we cannot take
a mean of this variable.
